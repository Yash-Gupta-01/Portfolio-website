# Power-Verb Bank (for résumé bullet leading verbs)

Use this when the verb audit (`grep` for repeated `\item` leading words) shows a verb used 3+ times. Swap by **kind of work**, not by volume — the replacement must still be true to what was done. A bullet that *contributed* to a team-owned system should not lead with "Architected" or "Led"; reach for "Built," "Implemented," or "Contributed to" instead. Loudness is not strength; accuracy is. (This is subordinate to the skill's Honesty Rules.)

## Contents
- Build / create
- Optimize / improve
- Design / architect (use only when ownership is real)
- Lead / own (use only when leadership is real)
- Debug / fix
- Analyze / investigate
- Automate / integrate
- Ship / deliver

## Ship / deliver

## Verbs to avoid leading with (weak / passive)
Responsible for, Helped, Assisted, Worked on, Participated in, Involved in, Handled, Dealt with — these describe presence, not impact. Replace with a verb above plus a metric (per the XYZ/HAMS framing in SKILL.md).
